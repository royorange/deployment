# 2026-10-19 本地验收

## 2026-10-21 统一配置与运行协议（0.7.0）

用户维护的可选导入导出入口统一为 `.project-setup/{environment}/.env`；默认不导出账号管理 Token 或特权清理 Key。保留变量选择、私有权限与 Git 忽略检查；不同当前值仅显示名称，显式选择保留或替换。旧文件不自动删除，旧预设 schema 继续兼容，默认菜单不再要求维护 app/deploy/pages 或原始 Token 文件。

组件 `runtimeFields` 显式选择运行敏感字段，在信任已提交适配器后才按需读取并冻结，v2 stdin 用于所有发布阶段；声明空数组时发送空对象，没有声明时保留 v1。完整账号凭据、其他环境值和清理权限不能进入请求。Pages 保留单次操作 Token 环境注入，并不接收应用或 Tunnel 连接 Key。源码、CI 与迁移门禁保持原路径。

- 工具 281 项测试通过，行覆盖 97.16%、分支覆盖 87.99%；新增运行字段白名单、v1/v2 兼容、信任前不访问 Key、Ref/URL 不一致阻断、运行值冻结、adapter echo 与错误截断前脱敏、环境隔离、统一路径、权限、管理 Token 导入隔离和冲突决策回归。
- lint、typecheck、build、format 检查与独立 tarball 安装测试通过；打包测试仍验证仓库外安装与默认加密存储重开。
- 本轮不写入真实 Cloudflare、Supabase 或 SSH 服务，不执行托管迁移。消费项目适配器负责内部运行文件隔离；工具单测不代表真实云端部署成功。没有自动读写 `.env`，内存/无保险库模式语义保持不变。

- 271 项测试通过，行覆盖率 97.10%、分支覆盖率 87.86%；lint、typecheck、format、build 和独立 tarball 安装检查通过。代码、TypeScript 和安全复审发现的问题均补回归修复。
- 发布检查覆盖最新同 SHA/工作流/仓库的 CI、重试和失败结果、来源仓库、干净索引、Git 替换对象与隐藏标志、适配器执行前源码复验、窄化子进程环境及凭据脱敏。真实 GitHub 只读查询验证已有 Fulcord 提交的 CI 门禁可用，没有触发构建或部署。
- 官方迁移从已提交 SQL 构造冻结快照，预演、应用后复验；取消、未知输出或未确认不会继续部署。阶段回执保留数据库已应用与后续失败的区别；项目自管迁移暂阻塞自动发布，不混用账本。
- 默认 PATH 实际优先命中 `/opt/homebrew/bin/project-setup` 的旧 0.3.0，而此前更新的是 `~/.local` 副本。本轮两份都安装为 0.6.0；实际默认命令 PTY 验证六入口、保存合成 SSH 设备、退出重开、显示严格连接命令以及设备文件 0600。临时记录已清理，未建立网络连接。
- 配套 Fulcord：92 项应用测试、51 项部署测试、lint、typecheck、format 和应用 build 通过；真实临时 Git 与无网络远端脚本沙箱验证候选版本、配置指纹和失败恢复。没有对真实 AWS 执行写入、创建 Tunnel/DNS、应用托管迁移或发布应用。

真实发布还需准备账号权限、运行文件、镜像 digest 和拉取权限；Fulcord 的手动构建工作流需进入默认分支才能注册，构建产物 digest 仍需录入配置。基础健康检查不替代业务读写验收，生产发布与数据库回滚不在本轮自动执行范围。

## 2026-10-20 向导与 shimau 对照（0.5.0）

对照 shimau 的静态前台、独立后台、Go API、Supabase 数据库/Storage、Firebase 登录、Lightsail 容器与 Cloudflare 访问链路。shimau 的 `public.schema_migrations(filename)` 由应用维护，不可直接迁为官方 CLI 历史；`/healthz` 返回 200 不能证明数据库、Storage 或认证可用。现有项目的环境文件导入、地址拼接、可选能力静默关闭和人工 Access 设置不能作为通用工具的就绪依据。

| 范围               | 本次实现                                                 | 仍由项目/后续能力负责                                   |
| ------------------ | -------------------------------------------------------- | ------------------------------------------------------- |
| 菜单和恢复         | 外层六项；嵌套返回；按当前配置重算；缺项可进入操作       | 切项目通过保存退出后重开                                |
| 前台/后台/API/任务 | 组件声明、独立 Origin/项目/环境分支、认证方式选择        | 消费项目具体构建、发布顺序和运行文件                    |
| Pages              | 真实部署列表与分支状态；保留自定义域名；不拼预测 URL     | 实际访问、Access 策略和默认地址绕过验证                 |
| AWS/Tunnel         | 复用既有整站准备能力，明确拓扑适用范围                   | 独立 API、Worker/Access 私有链路验收和项目发布          |
| 数据库与认证       | 区分 Firebase/Supabase；迁移策略门禁；人工初始化提示     | 精确回调声明、远端账本检测、受限角色/executor/bootstrap |
| 持续运营           | 项目声明 Storage、后台任务、可选集成、日志与恢复检查说明 | 真正的业务读写测试、告警、备份恢复与回滚执行            |
| 凭据与导入导出     | 复用统一加密保险库和环境隔离；组件字段可映射导出         | 原生隔离 `--env-file`、自动脱敏操作审计                 |

人工要求和未知证据不会变为“已完成”，HTTP 200、Key 存在或 Secret 名称存在不代表业务通过。所有新增自动化验证均使用合成数据，未修改真实服务或发布应用。

本轮 219 项测试通过，行覆盖率 97.13%、分支覆盖率 87.31%；lint、typecheck、format、build、独立 tarball 安装验证通过。实际 PTY 验证环境选择、六入口、向导用途/位置提示、逐级返回与正常退出；0.5.0 安装至本机后，再实走无 `--root` 的当前项目选择到主菜单并正常退出。代码、TypeScript 与安全复审发现的多组件旧绑定、默认项目复用、字段类型和导航标识冲突已补回归并修复。
