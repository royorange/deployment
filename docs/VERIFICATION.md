# 2026-10-19 本地验收

## 2026-10-20 向导与 shimau 对照（0.5.0）

对照 shimau 的静态前台、独立后台、Go API、Supabase 数据库/Storage、Firebase 登录、Lightsail 容器与 Cloudflare 访问链路。shimau 的 `public.schema_migrations(filename)` 由应用维护，不可直接迁为官方 CLI 历史；`/healthz` 返回 200 不能证明数据库、Storage 或认证可用。现有项目的环境文件导入、地址拼接、可选能力静默关闭和人工 Access 设置不能作为通用工具的就绪依据。

| 范围               | 本次实现                                                 | 仍由项目/后续能力负责                                   |
| ------------------ | -------------------------------------------------------- | ------------------------------------------------------- |
| 菜单和恢复         | 外层六项；嵌套返回；按当前配置重算；缺项可进入操作       | 切项目通过保存退出后重开                                |
| 前台/后台/API/任务 | 组件声明、独立 Origin/项目/环境分支、认证方式选择        | 消费项目具体构建、发布顺序和运行文件                    |
| Pages              | 真实部署列表与分支状态；保留自定义域名；不拼预测 URL     | 实际访问、Access 策略和默认地址绕过验证                 |
| AWS/Tunnel         | 复用既有整站准备能力，明确拓扑适用范围                   | 独立 API、Worker/Access 私有链路验收和项目发布          |
| 数据库与认证       | 区分 Firebase/Supabase；迁移策略门禁；人工初始化提示     | 精确回调声明、远端账本检测、受限角色/executor/bootstrap |
| 持续运营           | 项目声明 Storage、后台任务、可选集成、日志与恢复检查说明 | 真正的业务读写测试、告警、备份恢复与回滚执行            |
| 凭据与导入导出     | 复用统一加密保险库和环境隔离；组件字段可映射导出         | 原生隔离 `--env-file`、自动脱敏操作审计                 |

人工要求和未知证据不会变为“已完成”，HTTP 200、Key 存在或 Secret 名称存在不代表业务通过。所有新增自动化验证均使用合成数据，未修改真实服务或发布应用。

本轮 219 项测试通过，行覆盖率 97.13%、分支覆盖率 87.31%；lint、typecheck、format、build、独立 tarball 安装验证通过。实际 PTY 验证环境选择、六入口、向导用途/位置提示、逐级返回与正常退出；0.5.0 安装至本机后，再实走无 `--root` 的当前项目选择到主菜单并正常退出。代码、TypeScript 与安全复审发现的多组件旧绑定、默认项目复用、字段类型和导航标识冲突已补回归并修复。

- 本机旧安装无法识别 Fulcord 新 AWS 映射的退出问题已复现；更新至 0.4.0 后实际 PTY 选择当前项目、staging、进入新建保险库口令成功，并取消退出。没有代用户设置真实保险库口令。
