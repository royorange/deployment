# 2026-10-19 本地验收

## 2026-10-26 Tunnel 凭据来源引导（0.7.3）

只读代码调查确认，旧流程只有 `@cloudflareTunnelManagement` 明确绑定时才使用专用 Token；否则直接读取当前 Cloudflare 登录。Wrangler 绑定会执行 `auth token` 和 `whoami`，不会进入手动 Token 输入。手动输入原本已使用隐藏框，但在账号别名、说明及浏览器确认之后才出现，通用账号和 CI Token 选择也不表示已完成 Tunnel 管理绑定。

本版未绑定时先选择专用 Token、显式复用当前登录或返回；专用 Token 就地复用连接事务，验证失败恢复原绑定，不回退到其他凭据。官方 profile 的身份与账号校验保留；失败返回明确配置入口，原始 stderr 不显示，并提示只在明确的隐藏输入框粘贴。没有修改官方登录存储、保险库保存时机或真实账号配置。

- 291 项工具测试通过，行覆盖 97.36%、分支覆盖 88.14%；其中 10 项 Tunnel 管理凭据专项测试覆盖未绑定返回、就地设置、失败回滚、显式官方登录身份复验、缺失专用密钥不回退及隐藏输入。
- lint、typecheck、build、format 与独立安装包检查通过；验证仅使用合成客户端和凭据，没有读取真实保险库或执行资源写入。 本机两处全局安装更新到 0.7.3，独立 PTY 验证缺少 Tunnel 绑定时的来源选择和返回，无 provider 调用或持久写入；工具自身审计也无已知漏洞。

## 2026-10-26 项目与环境专属 Tunnel upstream（0.7.2）

配置向导从已校验的 Tunnel 名称生成 `http://${project}-${environment}:3000`，预览、合并检查和写入使用同一个值。组件需先在项目私有网络声明同名别名，连接器加入该网络。低层 `mergeTunnelIngress` 的 `app:3000` 默认保留兼容。旧项目必须先部署并验证别名，再确认将对应域名的旧 `http://app:3000` 路由改为新地址；工具不会在启动、预览或取消时自动改写线上路由。

- 285 项工具测试通过，行覆盖 97.17%、分支覆盖 88.16%；新增 staging/production、确认/取消四种组合回归，验证专属服务名、旧路由明确确认、保留无关 ingress 和已有 originRequest，以及取消不写。数字开头的合法项目可正常使用派生别名；服务名在资源读取/写入前校验，数字 IP、十六进制 IP、localhost 和无效端口继续拒绝。
- lint、typecheck、build、format 与独立安装包检查通过。Fulcord 示例同步其私有网络别名要求；AWS 新模板提示使用相同规则。
- 验证使用合成 Cloudflare 客户端，没有创建 Tunnel/DNS、修改线上入口或访问真实账号。

## 2026-10-21 统一配置与运行协议（0.7.0）

用户维护的可选导入导出入口统一为 `.project-setup/{environment}/.env`；默认不导出账号管理 Token 或特权清理 Key。保留变量选择、私有权限与 Git 忽略检查；不同当前值仅显示名称，显式选择保留或替换。旧文件不自动删除，旧预设 schema 继续兼容，默认菜单不再要求维护 app/deploy/pages 或原始 Token 文件。

组件 `runtimeFields` 显式选择运行敏感字段，在信任已提交适配器后才按需读取并冻结，v2 stdin 用于所有发布阶段；声明空数组时发送空对象，没有声明时保留 v1。完整账号凭据、其他环境值和清理权限不能进入请求。Pages 保留单次操作 Token 环境注入，并不接收应用或 Tunnel 连接 Key。源码、CI 与迁移门禁保持原路径。

- 工具 281 项测试通过，行覆盖 97.16%、分支覆盖 87.99%；新增运行字段白名单、v1/v2 兼容、信任前不访问 Key、Ref/URL 不一致阻断、运行值冻结、adapter echo 与错误截断前脱敏、环境隔离、统一路径、权限、管理 Token 导入隔离和冲突决策回归。
- lint、typecheck、build、format 检查与独立 tarball 安装测试通过；打包测试仍验证仓库外安装与默认加密存储重开。
- 本轮不写入真实 Cloudflare、Supabase 或 SSH 服务，不执行托管迁移。消费项目适配器负责内部运行文件隔离；工具单测不代表真实云端部署成功。没有自动读写 `.env`，内存/无保险库模式语义保持不变。
